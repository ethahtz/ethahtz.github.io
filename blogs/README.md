# Adding a blog post

1. Put your HTML file in this directory, for example `my-first-post.html`.
2. In `index.html` in this directory, add a new `<li>` at the top of the
   `<ul class="updates">` list, using the existing post as an example.
3. Update the link, title, and date for your post.

Posts are listed manually; adding an HTML file alone does not add it to the index.
Links from posts back to the blog index can use `./index.html`, and links to the homepage
can use `../index.html`.
